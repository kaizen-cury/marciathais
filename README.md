# Márcia Thais · Consultora Imobiliária

Landing page com lançamentos no Rio de Janeiro e em Niterói, simulador de financiamento MCMV/SBPE e captação de leads.

- `index.html` página principal
- `obrigado.html` página de obrigado (dispara conversões e abre o WhatsApp)
- `politica-de-privacidade.html` LGPD
- `config.js` contatos, e-mail dos cadastros e IDs de rastreamento

Site estático: pode ser publicado no Netlify ou GitHub Pages sem build.
